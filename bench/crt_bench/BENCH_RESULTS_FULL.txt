SUMMARY
========================================================================
 9B:  CRT within 12% of single-dGPU (10.1s vs 9.0s). iGPU helps.
35B:  CRT is the ONLY way to run this on GPU — it doesn't fit in 12GB.
      20.2 GB loaded across both GPUs. CPU is faster for now because
      the CRT dispatch path isn't yet fused into ggml's compute graph
      (it runs alongside, not replacing the main matmul).

The speed bottleneck for CRT is the per-matmul overhead:
  quantize → H2D → dual-ring matmul → D2H → Garner → dequantize
Each of these is a separate kernel launch + sync. Fusing the CRT
dispatch INTO ggml_mul_mat (replacing the default matmul on the hot
path) would eliminate the overhead and let CRT show its true win:
zero inter-GPU communication during compute.
