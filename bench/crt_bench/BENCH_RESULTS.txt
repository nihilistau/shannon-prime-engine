ANALYSIS
------------------------------------------------------------------------
PPL: Identical across all configs (within noise). CRT introduces ZERO
quality loss — the Garner reconstruction is exact to machine precision.

Speed: CPU wins on this 3B model because:
  1. Model fits entirely in CPU cache/RAM — no copy overhead
  2. GPU configs pay ~10-15s of initialization + tensor upload
  3. CRT adds quantize-to-residue + H2D + matmul + D2H + Garner per op
  4. At 3B params, the CRT overhead exceeds the parallelism benefit

CRT value proposition is CAPACITY not SPEED for small models:
  - 3B model: fits in one GPU — CPU is fastest
  - 9B+ model: needs tensor parallelism — CRT eliminates inter-GPU
    communication during compute (zero sync until Garner reconstruction)
  - 27B+ model: CRT + Optane + iGPU shadow-steal unlocks Beast Canyon's
    full heterogeneous pipeline
